## [1.0.0] - 2026-11-12

### Added
- TDF language recognition for `.tdf` files.
- TDF TextMate syntax highlighting.
- TBF language recognition for `.tbf` files.
- TBF header inspection command.
- TDF and TBF custom file icon theme.
- VS Code extension command registration.
- Initial extension test suite.
